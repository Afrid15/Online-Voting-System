# 🗳️ Online Voting System for Reality Show

A web-based voting platform that allows users to vote for contestants in reality shows. The system provides a seamless and secure interface for both users and administrators, enabling a digital voting experience with high accessibility, transparency, and ease of use.

## 📌 Short Description

This system replaces traditional SMS and phone-based voting methods with an interactive online platform. It’s designed for media teams to host and manage votes, while users can register, log in, and vote effortlessly. It minimizes cost, eliminates queues, and improves voter privacy and participation.

## ⚙️ Core Features & Functionality

- **User Login / Sign-Up**: Voters can register using their email and phone number to create an account.
- **Admin Login**: Admin has a default login and can customize the voting polls.
- **Voting Interface**: Users can preview and cast their vote in a clean, interactive UI.
- **Vote Collection**: Backend collects and stores votes securely.
- **Result Page**: After the voting deadline, users can see the winner on a dedicated results page.
- **Data Security**: Only admins can access vote data.
- **Scalable**: Designed to handle high volumes of votes efficiently.
